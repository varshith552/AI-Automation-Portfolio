## Projects

### Project 1: AI-Powered Email Classification and Automation System

**Domain:** AI Automation | LLM Applications

**Technologies:** Gmail, n8n, Ollama, Qwen 2.5 3B, JavaScript, REST API, JSON

An AI-powered email management system that automatically classifies incoming Gmail messages into four categories:

- Job Opportunity
- Interview
- Promotional
- General

The system uses an LLM to understand email content, JavaScript to validate classifications, and n8n to automate Gmail labeling.

**Key Features:**
- Automated email detection
- AI-based email classification
- JavaScript-based validation
- Automated Gmail label management
- Local LLM integration using Ollama
